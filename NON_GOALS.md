# D.O.G.G.O. Non-Goals

D.O.G.G.O. is not:

- an autonomous agent
- an executor
- an approval authority
- a policy authority
- a canonical-state owner
- an automatic remediation system
- an orchestration authority
- a hidden discovery crawler
- a self-expanding observer

Core negative statements:

```text
Detection does not imply remediation.
Knowledge does not imply authority.
Capability does not imply permission.
Recommendation does not imply authorization.
```
